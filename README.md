# Krishna Mishra Portfolio — GitHub Pages edition

This is a static HTML/CSS/JavaScript portfolio for GitHub Pages. It does not need a Node.js server or Supabase.

## Visitor statistics

The portfolio is prepared to use GoatCounter. Create a GoatCounter site/account, then copy its site code into `visitor-tracker.js` where `siteCode` is currently empty. After publishing that change, use `admin.html` to sign in to your GoatCounter dashboard. Do not put an account password, API key, or secret token in this public repository. Visits are not recorded until a real site code is configured.

## GitHub Pages

GitHub Pages is configured to publish the `main` branch from the repository root. The portfolio URL is https://krishnamishra0501.github.io/ca3-portfolio/.
