# Krishna Mishra Portfolio — GitHub Pages edition

This is a static HTML/CSS/JavaScript portfolio for GitHub Pages. It does not need Node.js, a server process, or Supabase.

## Visitor statistics

The portfolio is prepared to use GoatCounter. First create a GoatCounter site/account and copy the site code. In `visitor-tracker.js`, set `siteCode` to that code (the `myportfolio` part of `https://myportfolio.goatcounter.com`). Publish the change. Then use the GoatCounter sign-in link on `admin.html` to view visit statistics. Sign in with the GoatCounter account; there is no portfolio-local username or password.

The code is intentionally blank until a real GoatCounter site code is supplied, so visits are not yet recorded. Do not put a password, API key, or secret access token in the public repository.

## GitHub Pages

The included workflow publishes the repository root to GitHub Pages whenever a change is pushed to `main`. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source if Pages is not already enabled. The published project site URL will be `https://krishnamishra0501.github.io/ca3-portfolio/`.
